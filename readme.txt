Plugin hỗ trợ tùy biến Header, Body và Footer linh hoạt cho WordPress thông qua hệ thống Shortcode và giao diện quản lý mô-đun.

== Description ==

**HBFcustomizer** là công cụ mạnh mẽ dành cho các nhà phát triển và người dùng muốn toàn quyền kiểm soát bố cục website mà không cần can thiệp sâu vào code của Theme. 

Các tính năng chính:
*   **Header Customization**: Thay thế Header mặc định của các Theme như Astra, GeneratePress, Flatsome bằng mẫu thiết kế riêng[cite: 1, 2].
*   **Body Automation**: Tự động thay thế nội dung trang bằng các mẫu Body tùy chỉnh thông qua bộ lọc `the_content`[cite: 1, 2].
*   **Footer Management**: Dễ dàng chèn các mẫu chân trang chuyên nghiệp vào mọi vị trí trên website.
*   **Modular Design**: Hệ thống tệp tin mẫu tách biệt (header1.php, body1.php, footer1.php...) giúp quản lý và bảo trì code dễ dàng.
*   **Zalo Support**: Kết nối trực tiếp với cộng đồng hỗ trợ kỹ thuật tại Việt Nam.

== Installation ==

1. Tải thư mục `hbf-customizer` lên thư mục `/wp-content/plugins/`.
2. Kích hoạt plugin thông qua menu 'Plugins' trong WordPress.
3. Truy cập menu 'HBF Customizer' trong bảng quản trị để bắt đầu thiết lập các mẫu.

== Frequently Asked Questions ==

= Tôi có thể sử dụng plugin này với theme Astra không? =
Hoàn toàn được. Tuy nhiên, để Header/Body hiển thị tràn viền (Full Width), bạn nên chuyển cấu hình Layout trong Astra Settings sang "Stretched"[cite: 1].

= Làm sao để nhận thêm các mẫu thiết kế mới? =
Bạn có thể tham gia nhóm Zalo hỗ trợ để gửi yêu cầu hoặc nhận các bản cập nhật mẫu mới nhất.
